Press Ctrl+K to open quick search. Results appear as you type and match note titles first, then note bodies.

Wrap words in quotes to search for an exact phrase. Without quotes, every word must appear, but not necessarily next to each other.

Use tag:project to limit results to notes carrying that tag. Tags can be combined, so tag:project tag:urgent finds notes with both.

The index is rebuilt in the background after large imports. While it runs, the status bar shows a small spinner and recent notes may be missing from results.

Search covers text inside PDF attachments when the optional OCR component is installed. Scanned images are processed once and cached locally.

Saved searches live in the sidebar. Right-click a query and choose Pin to keep it, or drag it into a folder to organize related searches.

Date filters understand phrases such as before:2026-01-01 and after:last-week. Combine them with tags to build a quick weekly review.

Fuzzy matching tolerates one typo per word and can be turned off in Preferences if you prefer strict results.
