앱 잠금을 켜면 실행할 때마다 비밀번호나 지문을 묻습니다. 일정 시간 사용하지 않으면 자동으로 다시 잠깁니다.

노트북 단위로 암호를 걸 수 있습니다. 암호를 잊어버리면 복구할 방법이 없으니 안전한 곳에 적어 두세요.

모든 동기화 통신은 TLS로 암호화되며, 서버에는 종단 간 암호화된 데이터만 저장됩니다. 서비스 운영자도 노트 내용을 읽을 수 없습니다.

이중 인증을 켜면 새 기기에서 로그인할 때 인증 앱의 일회용 코드가 필요합니다. 복구 코드는 계정 생성 직후 한 번만 보여 줍니다.

화면 캡처 방지 옵션을 켜면 암호화된 노트북이 열려 있는 동안 스크린샷이 검게 나옵니다. 안드로이드와 아이폰에서 지원합니다.

공유 링크는 만료 날짜와 비밀번호를 지정할 수 있습니다. 링크를 만든 사람은 언제든 공유를 취소할 수 있습니다.

앱은 노트 내용을 분석하거나 광고에 쓰지 않으며, 사용 통계 전송은 기본값이 꺼짐입니다. 설정의 개인정보 탭에서 확인할 수 있습니다.

보안 문제를 발견하면 공개 이슈 대신 보안 신고 주소로 알려 주세요. 영업일 기준 3일 안에 답변합니다.
